# Argi 0.2.0

Argi 0.2.0 strengthens memory safety and explicit resource control, and expands
core collections and everyday text utilities.

Argi remains experimental. Language contracts, library APIs, and tooling may
change incompatibly between releases.

## Language and safety

- Automatic deterministic cleanup and compile-time checks for value validity
  and reference lifetimes across moves, cleanup, and storage reuse.
- Checked bounds and alignment in supported allocation and collection paths.
  Raw-pointer operations retain explicit proof obligations; see
  [the safety model](../description/34_safety_model.md).
- Explicit allocator selection through capabilities.
- `assume` supplies named inputs lexically; `reach` propagates
  dependencies through calls.
- Runtime dynamic dispatch through `Virtual`, with checked conversions from
  concrete values.
- Capability-based error tracing with `NoopErrorTracer` and
  `FixedSizeErrorTracer`.
- Improved fallible initialization checks, contextual aggregate typing, and
  diagnostics for incompatible numeric assignments and generic constraints.

## Core library

- Composable page, general-purpose, and arena allocators.
- Collection contracts for dynamic arrays and views, plus generic search,
  reversal, sorting, and binary search.
- Generic `HashMap` and `HashSet` with explicit hash/equality policies and
  copyable keys and values; fixed-capacity `RingBuffer`.
- Byte-oriented text search, prefix/suffix checks, ASCII trimming, splitting,
  joining, and replacement.
- Checked parsing of fixed-width signed and unsigned integers.

## Tooling and platforms

- LSP semantic highlighting distinguishes symbol roles, and basic completion
  suggests names, fields, and named arguments while editing.
- `argi check` validates all function bodies, including unreachable functions.
- `--release` builds optimized executables; build output can also emit LLVM IR
  or object files.
- The installed compiler includes core and resolves it from its installation
  prefix.
- Linux and macOS are validated in native CI. Building the compiler requires
  Zig 0.16.x and LLVM 21.
