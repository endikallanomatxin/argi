# Argi 0.3.0

Argi 0.3.0 redefines polymorphism around contracts and expands native integration,
libraries, and developer tools. Argi remains experimental, and this release
includes breaking language and library changes.

## Language and safety

- `Contract` and `implement` replace `Abstract` and global function overloads.
  Contracts support multiple participant types, associated types and constants,
  and generic implementations with specialization. Multiple dispatch now belongs
  to contracts; ordinary functions cannot be overloaded.
- Construction, destruction, conversion, copying, iteration, I/O, allocation,
  and operators share this contract model throughout core and more. `Init`,
  `Deinit`, and `Convert` replace the previous lifecycle and conversion mechanisms.
- Safety contracts let APIs declare how operations borrow, retain, invalidate,
  or transfer resources, including behavior that depends on success or failure.
  The compiler checks these guarantees for both static and supported virtual calls.
- Local Errable handlers, reporting returns with `!!!`, no-result `main`, and
  checked deferred actions simplify error handling. Moving `for` loops support
  consuming collections while cleaning up their elements correctly.
- Positional compile-time arguments, richer pipe expressions, large-value returns,
  and improved type and error diagnostics.

## Native interoperability and platforms

- Typed C imports and exports, including supported structs and unions, incomplete
  types, enums, and function-pointer callbacks. Foreign calls require explicit
  FFI permission; builds declare their native libraries and object files.
- Linux x86_64/ARM64 cross-compilation with configured C toolchains, plus LLVM IR
  optimization for release builds.
- Native Windows development with UTF-8 paths and arguments, binary streams,
  and platform runtime support.
- Linux and macOS binary packages for x86_64 and ARM64 include core, more, and
  non-system runtime dependencies. A system C linker is still required.

## Libraries

- Owning maps and sets, deques, priority queues, and bit sets, with borrowed
  iteration and automatic cleanup.
- Block and buffered I/O, bounded reads, owned lines, byte cursors, and endian
  operations. Filesystem traversal, temporary directories, CLI options, processes,
  and blocking DNS/TCP/UDP.
- Checked arithmetic, floating-point parsing/formatting and math, UTF-8 utilities,
  entropy, clocks, UTC/RFC 3339 dates, UInt32 atomics, and cooperative cancellation.
- Official more modules for linear algebra, semantic versions, URIs, logging,
  hex/Base64, JSON validation/tokenization, and CSV. Matrix operations check
  dimensions at compile time and can specialize their result representation.
- Optional CPython 3.12+ embedding with owned objects, calls, conversions,
  exception capture, bulk numeric transfers, and a typed NumPy vector wrapper.
  Ordinary compiler builds require no Python dependencies.

## Compiler and developer tools

- Reuse of unchanged modules across CLI builds, parallel module analysis, and
  cached LSP results. Executable builds check the safety of used implementations;
  `argi check` and editor diagnostics also check unused bodies.
- Source formatting through the CLI and LSP, hierarchical document symbols,
  and navigation from constructor calls to their implementations.
- Cat, echo, word-count, tree, Python CSV-report, and weighted-regression examples.
  CI covers Linux, macOS, Windows, and Python 3.12/3.14. Release packages are
  tested outside the checkout with project tooling and examples in debug and
  release modes.
