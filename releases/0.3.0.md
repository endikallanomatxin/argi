# Argi 0.3.0

Argi 0.3.0 adds practical native tooling, a much broader standard library, and
optional Python integration. Argi remains experimental; language and library
APIs may change incompatibly.

## Language and compiler

- Type-associated constructors and destructors, no-result `main`, reporting returns with `!!!`, local Errable
  handlers, and checked deferred cleanup.
- Moving `for` loops, generic iterator resolution, bound associated virtual
  types, richer pipe expressions, and positional generic type arguments.
- Caller-owned storage for supported references returned from bounded locals,
  stronger ownership checks, and clearer type and error diagnostics.
- Typed C imports/exports, supported aggregate ABIs, incomplete native types,
  and checked concrete C callbacks, with explicit FFI and link dependencies.
- Persistent module reuse, LLVM IR optimization, target-aware compilation,
  and Linux x86_64/ARM64 cross builds with configured C toolchains.

## Libraries

- Owning collections, deques, priority queues and bit sets; borrowed iteration
  and move-aware cleanup.
- Block and buffered I/O, bounded reads, line iteration, endian operations,
  byte cursors, and transfers using destination buffers.
- Filesystem traversal and metadata, temporary directories, CLI options,
  processes, blocking DNS/TCP/UDP, clocks, UTC dates, and RFC 3339.
- Checked arithmetic, floating-point parsing/formatting and math, UTF-8
  utilities, entropy, UInt32 atomics, and cooperative cancellation.
- Official more modules for dense linear algebra, semantic versions, URIs,
  logging, hex/Base64, JSON validation/tokenization, and owning CSV records.
- Optional CPython 3.12+ embedding, owned objects, calls and conversions,
  exception capture, bulk numeric copies, and a typed NumPy vector wrapper.
  Ordinary compiler builds require no Python dependencies.

## Developer experience

- CLI/LSP source formatting, hierarchical symbols, faster completion and
  navigation through cached results, and go-to-definition for initializers.
- Native Windows development with UTF-8 paths/arguments and binary streams.
  Installations bundle core and more; binary archives remain Linux/macOS
  x86_64 and ARM64.
- Practical cat, echo, word-count, tree, and Python CSV-report usecases.
  Native CI covers Linux/macOS, Windows, and Python 3.12/3.14.
