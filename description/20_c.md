# C subset

Argi has:

- CFunction
- CUnion
- CEnum

For interoperability with C code.

Current baseline:

- `CFunction` currently aliases the existing `ExternFunction` declaration
  shape and uses the same C ABI lowering in codegen.
- C string boundaries use raw `&Char` plus explicit helpers in `core/strings/c_strings.rg`.
- non-owning mutable `pointer + length` views live in core as
  `ArrayView#(.t: Type)`.
- raw C declarations still keep pointer-oriented array parameters such as
  `fread`, `fwrite` and `memcpy`.
- language-level wrappers in `core` should prefer `ArrayView#(.t: UInt8)` for
  byte buffers and lower to those raw pointer parameters at the FFI edge.
- richer array/function/calling-convention interop remains a later step.
