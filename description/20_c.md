# C subset

Argi has:

- CFunction
- CString
- CUnion
- CEnum

For interoperability with C code.

Current baseline:

- `CString` is available.
- non-owning `pointer + length` views live in the language/core as
  `ArrayView#(.t: Type)`, rather than as a C-specific container.
- richer array/function/calling-convention interop remains a later step.
