# C subset

Argi has:

- CFunction
- CArray
- CString
- CUnion
- CEnum

For interoperability with C code.

Current baseline:

- `CString` is available.
- `CArray#(.t: Type)` is a non-owning `data + length` wrapper with indexed
  access.
- richer function/calling-convention interop remains a later step.
