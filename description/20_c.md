# C subset

Argi has:

- CFunction
- CUnion
- CEnum

For interoperability with C code.

Current baseline:

- C string boundaries use raw `&Char` plus explicit helpers in `core/strings/c_strings.rg`.
- non-owning mutable `pointer + length` views live in core as
  `ArrayView#(.t: Type)`.
- richer array/function/calling-convention interop remains a later step.
