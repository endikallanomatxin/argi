# 0.5 — Concurrency

Order: ownership-aware transfer → synchronization and worker pool → structured tasks.

Architecture and remaining semantic obligations: [concurrency](concurrency.md).

- Extend plain-value tasks to checked owner/reference transfer and cross-thread
  lifetimes without weakening join-before-cleanup.
- Add reusable workers, synchronization, and required atomic widths/order policies.
- Integrate System.executor after native-only virtual methods can coexist with
  System-based VM and compile-time execution.
- Integrate cancellation/deadlines with tasks and interruptible native waits.
- Validate with a worker or server application.

Unscheduled: explicit closure captures, module runtime initialization,
slot-owner/suballocation APIs and additional platforms. Other topics have their
own notes in this directory.
