# 0.5 — Concurrency

Order: cross-thread transfer rules → OS threads → synchronization → tasks/runtime.

Architecture and remaining semantic obligations: [concurrency](concurrency.md).

- Define value/reference transfer, cross-thread lifetimes, and cleanup.
- Add thread handles, synchronization, and required atomic widths/order policies.
- Integrate cancellation/deadlines with tasks and interruptible native waits.
- Validate with a worker or server application.

Unscheduled: explicit closure captures, module runtime initialization,
slot-owner/suballocation APIs and additional platforms. Other topics have their
own notes in this directory.
