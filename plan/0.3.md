# 0.3

## Release purpose

Make Argi easier to develop with and useful for native tools and libraries:
faster rebuilds, practical C interoperability, cross-compilation, and native
Windows support. Include optional Python embedding in `more` to access existing
Python libraries. Add small everyday utilities without coupling the release to
networking, concurrency, or a new execution engine.

## Remaining preparation

- [ ] Validate optional CPython embedding on the supported native platforms;

- [ ] Correct generic overload selection when a previously instantiated
