# 0.3

## Release purpose

Make Argi easier to develop with and useful for native tools and libraries:
faster rebuilds, practical C interoperability, cross-compilation, and native
Windows support, readable source formatting, and fallible program entrypoints.
Include optional Python embedding in `more` to access existing
Python libraries. Include system entropy, URI utilities, dense linear algebra,
and richer pipe expressions. Include local Errable handlers, fully bound
associated virtual types, an owning growable Deque, blocking DNS/TCP/UDP,
and an optional typed NumPy vector consumer. Include checked endian operations
and byte cursors, Deque/map/set iteration, strict UTF-8 utilities, bounded testing
diagnostics, block stream helpers, and directory,
metadata, seek/truncate, and temporary directory APIs. Keep concurrency and a new
execution engine independent from this release.
