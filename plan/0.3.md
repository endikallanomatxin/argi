# 0.3

## Release purpose

Make Argi easier to develop with and useful for native tools and libraries:
faster rebuilds, practical C interoperability, cross-compilation, and native
Windows support, readable source formatting, and fallible program entrypoints.
Include optional Python embedding in `more` to access existing
Python libraries. Include system entropy, URI utilities, dense linear algebra,
and richer pipe expressions without coupling the release to networking,
concurrency, or a new execution engine.
