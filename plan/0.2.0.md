# 0.2.0

Goal: make Argi's memory-management and temporal-safety model coherent enough
for the compiler and core library to build on it.

- [x] Define `&` as read permission and `$&` as aliasable read/write permission.
- [x] Track places and structural projections independently.
- [x] Reject use-after-move and use-after-deinit.
- [x] Track dependencies and root invalidation through control flow.
- [x] Infer and compose interprocedural temporal summaries.
- [x] Preserve storage across consuming calls and construct results in their
  destination storage.
- [x] Implement Virtual fat pointers and abstract dispatch with conservative
  dependency envelopes.
- [x] Add `RawPointer<T>` and privileged fresh/inherit establishment primitives.
- [x] Keep ArenaAllocator backed by a caller-selected allocator and model its
  allocations as one common validity domain.
- [x] Cover aliasing, move, cleanup, replacement, structural places, arenas,
  raw boundaries and conservative dynamic invalidation in feature tests.
- [ ] Replace remaining core-only temporal annotations with inferred facts or
  centralized raw primitives as relevant core APIs become raw-pointer based.
- [ ] Preserve typed safe references in every view; StringView retains a raw
  address compatibility field pending typed-reference pointer arithmetic.
