# 0.2.0

Goal: make Argi's memory-management model sufficiently settled and implemented
that the compiler and core library can rely on it.

- [x] Implement the `&`, `$&`, `$$&` reference model.
- [x] Add static temporal safety based on provenance, invalidation and liveness.
- [x] Integrate invalidation domains with `Allocation` and arena-style storage.
- [x] Propagate temporal dependencies through values and fixed-point function
  summaries, including concrete Abstract monomorphizations.
- [x] Propagate post-state dependencies through calls and seed symbolic hidden
  dependencies for composite inputs.
- [x] Propagate fresh post-state dependencies through type initializers into
  their stable destination bindings.
- [x] Converge loop and interprocedural states to a fixed point, with a
  conservative widening fallback.
- [x] Replace temporal behavior inferred from Core paths/function names with
  explicit invalidation, storage-root, trusted and raw-boundary contracts.
- [x] Express invalidation of owned roots stored inside aggregate values with
  precise dependency-path contracts, without invalidating unrelated borrows.
- [x] Preserve owned-root provenance across raw pointer-returning Core helpers
  with explicit dependency-return contracts.
- [x] Publish conservative owned-storage invalidation for collection operations
  that may reallocate, including `DynamicArray.push`.
- [x] Require explicit raw/trusted boundaries for contracts that manufacture a
  fresh hidden dependency post-state.
- [x] Give uncontracted extern calls conservative invalidation and return-
  dependency envelopes.
- [x] Preserve reference validity across local `~` transfers when storage must remain
  stable.
- [x] Preserve backing storage for consuming transfers across internal calls by
  passing input storage addresses.
- [x] Construct internal function outputs through destination addresses and
  propagate self-dependent output paths back into caller provenance.
- [x] Remap self-dependent outputs into field, array-element and indirect
  destinations, and validate later subobject invalidation against those Places.
- [x] Reject address-dependent transfers whose return/container lowering still
  requires destination passing.
- [x] Cover representative containers, views, arena regions, stored references,
  control flow and abstract calls with tests.
- [x] Add a conservative `Virtual` temporal envelope once Virtual types and
  vtable dispatch exist in the language.
  - [x] Add the identified `Virtual#(.abstract: A)` fat-pointer representation,
    checked `to_virtual` erasure, and provenance-preserving data envelope.
  - [x] Generate virtual-safe vtables and indirect calls for Abstract
    requirements using the shared storage-address ABI.
  - [x] Propagate the conservative temporal envelope through every
    dependency-carrying field of multi-output virtual calls.
  - [x] Prevent read-only or mutable references from being upgraded through
    `to_virtual`; Abstracts with `$$&Self` methods require `$$&Concrete`.

The milestone does not require every advanced optimization or erasure/FFI corner
case, but the core model should be coherent and usable enough to build on.
