# 0.2.0

Goal: make Argi's memory-management model sufficiently settled and implemented
that the compiler and core library can rely on it.

- Implement the `&`, `$&`, `$$&` reference model.
- Add static temporal safety based on provenance, invalidation and liveness.
- Integrate invalidation domains with `Allocation` and arena-style storage.
- Propagate temporal dependencies through values and function summaries.
- Preserve reference validity across `~` transfers when storage must remain
  stable.
- Cover representative containers, views, abstract calls and a conservative
  `Virtual` baseline with tests.

The milestone does not require every advanced optimization or erasure/FFI corner
case, but the core model should be coherent and usable enough to build on.
